# Звуки: источники и лицензии

Сюда кладутся настоящие записи вместо звуков-заглушек, которые игра генерирует в коде.
Принимаются только файлы с лицензией **CC0 1.0** (public domain): их можно менять,
продавать в составе игры и не указывать автора. Указываем всё равно, чтобы было видно,
откуда файл и что лицензия проверена.

Как это работает: `scripts/sound_files.gd` ищет `res://sounds/<имя>.ogg` (или `.wav`).
Если файла нет, звучит прежняя заглушка, так что недостающие звуки ничего не ломают.
Петли (холодильник, вода, звонок, гул, фон) лучше класть в `.ogg`: игра сама включает повтор.

## Какие имена ждёт игра

| Файл | Где звучит |
|---|---|
| `step_wood_0` … `step_wood_3` | шаги по деревянному полу квартиры (и стук брошенных предметов) |
| `step_tile_0` … `step_tile_3` | шаги по плитке на кухне и в ванной |
| `fridge` | гудение холодильника, петля |
| `water` | вода из открытого крана, петля |
| `drip` | капля из крана |
| `creak` | скрип двери и дверцы холодильника |
| `door_thud` | дверь захлопнулась |
| `clock_tick` | тиканье часов в комнате |
| `switch_click` | выключатель |
| `synth/ring` | звонок брошенного телефона, петля |
| `synth/beep` | пришло SMS |
| `synth/drone` | гул рядом с Тенью, петля |
| `synth/ambient` | мрачный фон меню и уровней, петля (идёт на шину «Музыка») |
| `synth/tick` | шорох при наведении на кнопку меню |
