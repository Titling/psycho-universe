# Godot 4.3 и новее: что учитывать

Проект сделан на **Godot 4.3**, но его открывают и в более новых версиях
(README предлагает «4.3 или новее»). Поэтому код должен работать в 4.3 и не
ломаться в 4.4–4.7.

Сведения взяты из справочника Claude Code Game Studios (MIT, проверено авторами
17.10.2026) и официальных руководств по миграции:
https://docs.godotengine.org/en/stable/tutorials/migrating/

## Чего нет в 4.3 (не использовать)

| Что | С какой версии |
|-----|----------------|
| Переменное число аргументов в функциях (`...`) | 4.5 |
| Декоратор `@abstract` | 4.5 |
| `Resource.duplicate_deep()` | 4.5 |
| Узел `FoldableContainer` | 4.5 |
| Буфер трафарета (stencil) в шейдерах, SMAA, Shader Baker | 4.5 |
| `AreaLight3D`, HDR-вывод | 4.7 |
| `InputEvent.DEVICE_ID_MOUSE` / `DEVICE_ID_KEYBOARD` | 4.7 |
| Файлы `.uid` рядом со скриптами и шейдерами | 4.4 (в 4.3 их нет, но если они появились после открытия в новой версии, их нужно коммитить вместе со скриптом) |

## Что ведёт себя иначе в новых версиях

| Версия | Изменение | Что делать у нас |
|--------|-----------|------------------|
| 4.4 | `FileAccess.store_*` возвращают `bool` (в 4.3 `void`) | Не использовать результат `store_*`, тогда код работает в обеих версиях |
| 4.6 | Jolt стал физикой по умолчанию для **новых** проектов | Наш проект сохраняет свою настройку, ничего не делать |
| 4.6 | Glow считается до тонмаппинга | Если включим glow, проверить картинку в новой версии |
| 4.6 | На Windows по умолчанию D3D12 | Нас не касается: у нас Compatibility (OpenGL) |
| 4.7 | Переопределённый метод наследует типизированный возврат и требует явный `return` | В переопределениях с типом возврата всегда писать `return` |
| 4.7 | Линии `CanvasItem` рисуются без сглаживающей каймы и выглядят тоньше | Если рисуем линии в UI, проверить толщину |
| 4.7 | `AudioStreamPlayer3D.area_mask` по умолчанию 0 | Если используем `audio_bus_override` у `Area3D`, явно выставить маску |
| 4.7 | В новых проектах другие настройки растяжения окна | Наш проект хранит свои настройки, ничего не делать |

## Уже было в 4.3 (можно использовать)

- `TileMapLayer` вместо `TileMap`.
- `#include` в шейдерах.
- `CompositorEffect` (но в рендере Compatibility он не работает, поэтому нам не подходит).
- `AnimationMixer` как база для `AnimationPlayer` и `AnimationTree`.

## Ограничения рендера Compatibility

- Нет compute-шейдеров. `GPUParticles3D` в 4.3 работают, но с ограничениями,
  поэтому для частиц на слабом железе надёжнее `CPUParticles3D`.
- Нет SDFGI, SSAO, SSR, объёмного тумана. Атмосферу делаем обычным туманом
  `Environment`, плёночным фильтром и светом.
- Эффекты на весь экран делаем шейдером `canvas_item` на `ColorRect` поверх
  картинки, как `shaders/film.gdshader`.
