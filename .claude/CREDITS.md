# Откуда взяты агенты и команды

Агенты в `.claude/agents/`, команды в `.claude/skills/` и справка
`docs/godot-versions.md` адаптированы из шаблона
[Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios)
(версия 1.2.0, коммит 05ad7c8). Их переписали под Psycho Universe: Godot 4.3,
рендер Compatibility, папка `scripts/`, тексты по-русски. Хуки, правила по
папкам `src/`, остальные агенты и файл `project.yaml` не переносились.
